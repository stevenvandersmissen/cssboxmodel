01

DE DOOS

Vergeet even dat het om tekst of plaatjes gaat. Voor CSS is alles een rechthoekige doos. Die doos heeft vier lagen, van binnen naar buiten: de inhoud (content), de binnenruimte (padding), het kader (border) en de buitenruimte (margin).

voorbeeld · de vier lagen
MARGIN · buitenruimte, altijd doorzichtig
BORDER · het kader
PADDING · binnenruimte, krijgt de achtergrondkleur
CONTENT · hier staat je tekst of foto

LEESWIJZER

width / heightstellen de inhoud in
paddingruimte binnen het kader
borderhet kader zelf
marginruimte buiten het kader

ONTHOUD DIT

Standaard telt width alleen de inhoud. Padding en border komen daar bovenop. Een doos met width: 200px en padding: 20px is in het echt 240 px breed. Rekenfout nummer één bij beginners.

02

CONTENT: BREEDTE & HOOGTE

Met width en height bepaal je hoe groot de inhoud van de doos is. Standaard maakt alles wat je daarna toevoegt (padding, border) de doos groter. Verderop leer je een truc om dat te veranderen.

VOORBEELD · CODE

.kaart {
  width: 300px;
  height: 120px;
  background-color: #ffd23f;
}

De gele vlakte is 300 × 120 px inhoud. Nog geen padding, geen border, geen margin.

VOORBEELD · RESULTAAT

300 × 120

Meet het maar na: exact 300 px breed en 120 px hoog.

REGEL DIE ALLES VERKLAART (STANDAARD)

totale breedte = width + padding links + padding rechts + border links + border rechts

Margin hoort hier niet bij: dat is lege ruimte buiten de doos. Oefening A rekent met deze regel.

DE TRUC: BOX-SIZING: BORDER-BOX

Standaard (content-box) telt width alleen de inhoud. Met border-box telt width alles mee: inhoud, padding en border. Je kiest dan de totale breedte zelf, en rekenen wordt een stuk makkelijker.

content-box (standaard) · width 220 px → totaal 268 px

Standaard

border-box · width 220 px → totaal 220 px

Border-box
* {
  box-sizing: border-box;
}

Veel ontwerpers zetten deze regel bovenaan hun CSS. Daarna blijft de breedte altijd gelijk, ook als je later padding of border toevoegt.

03

PADDING: RUIMTE BINNEN

Padding is de binnenruimte tussen de inhoud en het kader. De achtergrondkleur loopt door in de padding. Tekst die tegen de rand plakt? Dat los je op met padding, nooit met lege spaties of extra <br>-tags.

VOORBEELD · CODE

.kaart {
  background-color: #ffd23f;
  padding: 24px;
}

Rondom 24 px ademruimte. De gele kleur vult de padding mee.

VOORBEELD · RESULTAAT

Zonder padding: de tekst plakt tegen de rand.
Met padding: dezelfde tekst, 24 px ademruimte.

STENO: 1, 2, 3 OF 4 WAARDEN

padding: 20px;             /* alle 4 kanten */
padding: 10px 30px;        /* boven en onder: 10px · links en rechts: 30px */
padding: 10px 30px 40px;   /* boven: 10px · links en rechts: 30px · onder: 40px */
padding: 1px 2px 3px 4px;  /* klok mee: boven rechts onder links */

Ezelsbruggetje bij vier waarden: lees ze als een klok — boven, rechts, onder, links.

PROBEER ZELF · SCHUIF

Sleep aan de schuif en kijk wat er met de doos gebeurt.

Ik groei van binnenuit.

Let op: de inhoud blijft even groot, de doos wordt groter.

04

BORDER: HET KADER

De border is het kader om padding en inhoud heen. Een zichtbaar kader heeft een dikte, een stijl en een kleur nodig. Vergeet je de stijl, dan zie je helemaal geen kader.

VOORBEELD · CODE

.kaart {
  border-width: 4px;
  border-style: solid;
  border-color: #111111;
}

/* korter: alles in één regel */
.kader-kort {
  border: 4px solid #111111;
}

Beide schrijfwijzen doen exact hetzelfde. De korte vorm zie je het vaakst.

VOORBEELD · RESULTAAT

solid · volle lijn
dashed · streepjes
dotted · puntjes
double · dubbele lijn (min. 3px)
LET OP border: 4px #111111; zonder stijl doet niets: de standaardstijl is none. Dat kan ook per kant: border-top, border-right, border-bottom, border-left — handig voor één streep onder een titel.
05

MARGIN: RUIMTE BUITEN

Margin is de buitenruimte rond de doos: de afstand tot de buren. Margin is altijd doorzichtig — de achtergrondkleur van het element komt er nooit in. Ook margin kan met 1 tot 4 waarden in steno, net als padding.

VOORBEELD · CODE

.kaart {
  background-color: #ffd23f;
  margin: 20px;
}

Rondom 20 px lege ruimte. Geel zie je alleen binnen het kader, nooit in de margin.

VOORBEELD · RESULTAAT

Mijn gele vlak blijft even groot. Alleen de lege ruimte eromheen groeit.

PADDING OF MARGIN?

Vraag het zo: moet de ruimte dezelfde achtergrond krijgen als het element? Kies padding. Moet de ruimte leeg blijven, zoals de witruimte tussen twee kaarten? Kies margin.

GEK, MAAR WAAR: MARGES PLAKKEN

Twee dozen onder elkaar met elk margin: 20px krijgen geen 40 px tussenruimte, maar 20 px. Verticale marges plakken aan elkaar: de grootste wint. Horizontale marges tellen wel gewoon op.

06

CENTREREN MET MARGIN: AUTO

Een doos horizontaal centreren doe je met automatische zijmarges: links en rechts evenveel. De browser rekent dat zelf uit. Dit is het recept dat je uit het hoofd moet kennen.

HET RECEPT · CODE

.kaart {
  width: 520px;
  margin: 0 auto;
}

margin: 0 auto betekent: boven en onder 0, links en rechts auto. Twee gelijke marges duwen de doos precies in het midden.

PROBEER ZELF · KLIK

Ik ben 60% breed

Nu geldt: margin: 0; — de doos plakt links.

DRIE VOORWAARDEN — ALLE DRIE NODIG

  1. Het element is een blok (div, article, section, p, h1 … zijn dat vanzelf).
  2. Het heeft een breedte (width) die smaller is dan de ouder. Zonder breedte vult een blok alles — dan valt er niets te centreren.
  3. De linker- en rechtermarge staan op auto.

VEELGEMAAKTE FOUT: TEXT-ALIGN

text-align: center; centreert de inhoud (tekst, plaatjes) binnen de doos — niet de doos zelf. Wil je de doos in het midden van de pagina? Dan heb je margin: auto nodig. Ze doen dus iets anders en je gebruikt ze vaak samen: margin auto voor de doos, text-align voor de tekst erin.

alleen text-align: center

De tekst staat in het midden, maar de doos is nog even breed als de pagina.

alleen margin: 0 auto + width

De doos staat in het midden. De tekst erin staat nog links.

Vijf korte reeksen. Typ je antwoord in het vakje — je tekst blijft staan tot je de pagina herlaadt. De leerkracht verbetert; er staan geen antwoorden op deze pagina.

C · CENTREER DE DOOS

Maak de CSS af zodat de doos van 520 px horizontaal in het midden komt.

.kaart {
  : 520px;
  : 0 ;
}

En leg in één zin uit: waarom werkt dit niet als je de eerste regel weglaat?

D · WAAR OF NIET WAAR?

Kruis per stelling aan.

  1. Bij de standaardinstelling telt padding mee in de totale breedte van de doos.
  2. Margin krijgt de background-color van het element.
  3. Met text-align: center centreer je een doos met een vaste breedte.
  4. border: 4px solid red; doet hetzelfde als de drie losse regels border-width, border-style en border-color.

08

EINDOPDRACHT: MENUKAART

Je bouwt een menukaart voor een broodjesbar. Je krijgt de HTML, jij schrijft de CSS: een gecentreerde kaart met padding, een kader en buitenruimte. Alles wat je nodig hebt staat in 01–06.

start.html — kopieer en plak 
<!DOCTYPE html>
<html lang="nl">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Menukaart</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <article class="kaart">
    <p class="badge">VERS</p>
    <h1>Lunchkaart</h1>
    <ul class="gerechten">
      <li>Boterham Deluxe <span>€ 7,50</span></li>
      <li>Club kaas & spek <span>€ 6,00</span></li>
      <li>Veggie van de dag <span>€ 5,50</span></li>
    </ul>
    <p class="voet">Elke middag vers · tot 14.00 uur</p>
  </article>
</body>
</html>
style.css — zo begin je 
/* Naam: ______   Klas: ______
   Totale breedte van .kaart: ______ px
   (berekening: _________________________________) */

.kaart {
  /* gebruik width, margin, padding en border */
}
